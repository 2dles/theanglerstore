# Real product photographs

Drop a file here named for the product key, then point the catalog at it:

    public/products/surf-rod.jpg
    ↓
    src/lib/products.ts →  image: "/products/surf-rod.jpg"

The storefront picks it up everywhere — cards, product page, cart — with no
other change. Until then that product renders our own illustration.

Recommended: 1600×1200 (4:3), JPEG, under 400 KB. Shoot on a dark surface;
see IMAGES.md in the repo root for the full shot list.

⚠️ Only put images here that you took yourself, or that a supplier has given
you written permission to use. Do not save images from a supplier's website,
Amazon, or a Google image search — those belong to someone else. IMAGES.md
explains how to get ones you can legally use.
